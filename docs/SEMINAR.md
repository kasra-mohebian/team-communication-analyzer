# From seminar discussion to a working pipeline

The seminar discussed a text circulated as *The Two Foundations* from *Cybernetic Alchemy*, attributed in the course material to Peter Gloor and Claude (2025). A publisher record, ISBN and stable public edition have not been independently verified; this is a description of the seminar material, not a verified bibliographic citation. Its conceptual contrast between visible technical work and less visible emotional coordination motivated questions about what digital signals reveal and what automatic tools miss. The fictional analogy was a discussion aid, not empirical validation.

The group project then developed SocialCompass: parsers, measurable chat features, inferred networks, weak soft labels, model comparison and a dashboard. Comparing tools can expose disagreements and limitations; it does not prove that any tool reveals a hidden personality truth.

This public summary links the conceptual starting point to the code without distributing the book/chapter, original slides, personal Big Five scores or private classroom material. The completed empirical results and their limits are described in RESULTS.md.
