# Project provenance and changes

SocialCompass originated as collaborative university coursework. This repository presents a revised portfolio edition of that shared implementation, not a claim of sole authorship.

The original MIT notice in LICENSE credits SocialCompass — Team Communication Analyzer contributors and is preserved. Code and documentation are covered only to the extent the licensors hold those rights; the licence does not cover underlying datasets or grant permission to disclose personal information.

This edition adds a fictional offline demo, regression tests, parsing and probability-validation fixes, context-aware interaction graphs, cache invalidation and selected-aggregate publication checks. The README and research guides describe the current behaviour and its limitations.

The numerical values retained in the selected historical aggregate records are unchanged. Individual annotations, small-team profiles, private transcripts, identity maps, original reports/slides and the previous source history are excluded. Corrected code has not been fully retrained; future experiments must be labelled separately.
