# Selected historical aggregate results

This folder contains training-wide model evaluations, feature importance and combined annotation-agreement metrics from the completed course project.

`ml_results.json` contains a documented subset of fields. The small-team case study, domain-shift results and descriptions of small-group behaviour are excluded. Annotation-agreement files contain combined metrics only, without rater identifiers, per-rater comparisons or confidence subgroups. The retained numbers are unchanged; the other three JSON files match the reviewed source snapshot byte for byte.

Real chat text, member profiles, per-user annotations, small-team features and interaction edges are not included. These are recorded results, not a new run of the corrected code. See [results and limitations](../../docs/RESULTS.md) for their provenance and interpretation.
