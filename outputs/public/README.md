# Selected historical aggregate records

Only training-wide model evaluation, feature importance and aggregate annotation-agreement summaries are included. The ml_results.json is an explicitly documented field subset: case-study/domain-shift fields and narrative revealing small-group behaviour are omitted; retained scores are unchanged. Annotation agreement retains combined metrics only: rater identifiers, per-rater comparisons and confidence subgroups are omitted. Retained numbers are unchanged. The other three JSON files are byte-identical to the reviewed source snapshot.

No real member profiles, per-user annotations, small-team features, chat text or interaction edges are distributed. See docs/RESULTS.md for provenance and limitations. These are historical summaries, not results rerun with the corrected code.
